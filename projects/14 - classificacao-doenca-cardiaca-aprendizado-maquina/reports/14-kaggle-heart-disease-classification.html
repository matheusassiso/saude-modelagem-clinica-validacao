Kaggle Heart Disease Classification

Interpretable binary classification with validation and calibration

Matheus Assis de Oliveira

June 26, 2026

Abstract

This article presents the final project in the current portfolio roadmap: a Kaggle heart disease classification workflow. The dataset contains 303 records and a heart disease prevalence of 54.5%. The workflow compares logistic regression and decision tree models with stratified validation, ROC-AUC, confusion metrics, calibration bins, and standardized coefficient interpretation. The selected model is logistic, with holdout ROC-AUC of 0.863, accuracy of 80.3%, sensitivity of 87.9%, and specificity of 71.4%. This is a portfolio benchmark, not a clinical decision tool.

Introduction

Heart disease classification is a classic structured-data benchmark. It is useful for a portfolio because it requires the analyst to handle categorical-style numerical variables, evaluate binary classification metrics, and communicate model limits.

The research question is:

Which variables help classify heart disease presence,
and how can the model remain interpretable?

Methods

The workflow uses a stratified 80/20 holdout split and five-fold stratified cross-validation on the training set. Logistic regression is trained on standardized predictors, while the decision tree uses the original numeric feature scale. ROC-AUC is computed manually, and confusion metrics are reported at threshold 0.50.

Discussion

The selected model provides an interpretable classification benchmark. Logistic regression coefficients show which standardized predictors are associated with higher or lower predicted probability, while the decision tree provides a simple nonlinear comparison.

The model should be read as a teaching and portfolio artifact. In clinical settings, threshold choice would depend on screening goals, harm tradeoffs, prevalence, and external validation.

Limitations

The dataset is small, benchmark-oriented, and not sufficient for medical deployment. It lacks longitudinal clinical history, medications, symptoms, diagnostic imaging, care pathways, and representative sampling. The output is not medical advice, diagnosis, triage, or a clinical recommendation.

Conclusion

S14 completes the current portfolio roadmap with a validated, interpretable heart disease classification project. The workflow includes model comparison, ROC-AUC, confusion metrics, calibration, variable interpretation, and careful clinical limitations.
